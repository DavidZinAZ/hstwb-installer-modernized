Copy Amiga OS 3.2.3 files here.
Requires an installed Amiga OS 3.2, 3.2.1 or 3.2.2 base.
The fresh-image setup flow installs base 3.2 before applying this update.

Required update disks:
- Update3.2.3.adf
- Classes3.2.3.adf
- Extras3.2.3.adf
- DiskDoctor3.2.3.adf

Also provide Locale3.2.3-<language>.adf for each installed language,
and Modules<model>_3.2.3.adf for the selected machine when using an older ROM.
Native acceptance of the new companion-disk flow is in progress.
