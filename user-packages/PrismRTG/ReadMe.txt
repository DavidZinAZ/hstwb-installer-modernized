PrismRTG 1.1

Kickstart 3.1+, 68020+, supported RTG card. Replaces the active Picasso96 setup.

HstWB extracts the complete upstream package into the chosen drawer, displays the result and pauses until you press Enter. After HstWB finishes, open the drawer and run Install_PrismRTG to complete setup using the standard Amiga Installer. The upstream installer handles system components, configuration and backup choices. When preparing an image in an emulator, complete hardware setup on the final target machine.
