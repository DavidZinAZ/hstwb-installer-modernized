ZZ9000 Drivers 2.8.1
Default destination: SYS:Tools/Hardware/ZZ9000
Source: https://github.com/BlitterStudio/zz9000-drivers

This package copies files only. It does not run diagnostics, flash hardware,
replace Workbench, or add startup tasks.

Open ZZ9000Installer and double-click Install ZZ9000 on the target machine.
The official installer handles system components and hardware configuration.
Use a matching firmware/driver release. Nothing is activated during HstWB setup.
