A4091 Tools 42.39
Default destination: SYS:Tools/Hardware/A4091
Source: https://github.com/A4091/a4091-software

This package copies files only. It does not run diagnostics, flash hardware,
replace Workbench, or add startup tasks.

Tools and guide are extracted from the official A4091 support disk.
A4091.adf, a4091.device and a4091.rom are provided for manual use.
The device is not enabled and the ROM is not programmed by this package.
DevTest write modes and RDB tools can modify disks: read A4091.guide first.
