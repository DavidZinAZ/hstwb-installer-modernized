PrismNet 1.0.1

AmigaOS 3.1+, 68000+, suitable network driver. Disable the old TCP/IP stack startup before activating PrismNet.

HstWB extracts the complete upstream package into the chosen drawer, displays the result and pauses until you press Enter. After HstWB finishes, open the drawer and run Install_PrismNet to complete setup using the standard Amiga Installer. The upstream installer handles system components, configuration and backup choices. When preparing an image in an emulator, complete hardware setup on the final target machine.
