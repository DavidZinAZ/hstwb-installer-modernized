AmiFM 1.2

Default Amiga drawer: SYS:Utilities/AmiFM (customizable in native user-package assigns).

Workbench 3.0+. View uses MultiView/datatypes; Edit needs an editor; Extract needs XAD tools and libraries; Pack needs LhA. Optional helpers are not installed by HstWB.

Open AmiFM from this drawer to launch the file manager.

HstWB extracts the original release files, displays the result and waits for Enter. It does not run application setup, start services, mount devices or edit startup settings. After HstWB completes, follow the upstream instructions in Upstream-README.txt. An existing drawer containing Upstream-README.txt is retained without replacing files, protecting configuration and user data; use the upstream update procedure for an existing installation.

Public packages do not bundle AmiFM-1.2.lha because upstream has no explicit redistribution license. Download it from https://github.com/lainejones/AmiFM/releases/tag/v1.2 into the Windows user-packages/AmiFM folder before building an image. A verified local copy can be used privately.
