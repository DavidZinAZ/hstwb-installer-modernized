ADF-Blitzer 3.10 - optional HstWB user package

Requires OS 2+ and a 68000. Upstream reports testing through Kick/WB 3.2.
1 MB RAM is sufficient; upstream also reports 512 KB with a hard drive.

Open ADF-Blitzer directly from this drawer. No external files are required.
The left button writes an ADF image to a floppy, replacing its contents;
the right button reads a floppy into an ADF file. Choose DF0: through DF3:
using the Drive menu when multiple drives are available.

HstWB only extracts the application and its original documentation. It does
not launch the program, write disks or add startup entries. Existing staged
drawers with Upstream-README.txt are retained without overwriting files.
Read Upstream-README.txt and LICENSE.txt before use or redistribution.
Commercial use and paid distributions require author permission.
